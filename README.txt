PORTFOLIO — MONEAM WANNESSI

Contenu :
- index.html : page principale du portfolio
- style.css : design responsive et thèmes clair/sombre
- script.js : menu mobile, animations, progression de lecture et thème
- assets/moneam-photo.jpeg : photo de profil

Pour ouvrir le site :
1. Décompressez le dossier.
2. Ouvrez index.html avec Chrome, Edge ou Firefox.
3. Une connexion Internet est nécessaire uniquement pour charger les polices Google ; le site fonctionne aussi sans elles.

Pour publier gratuitement :
- GitHub Pages : créez un dépôt public, ajoutez tous les fichiers du dossier, puis activez Settings > Pages > Deploy from a branch > main > /(root).
- Vous pourrez ensuite partager l'adresse publique générée par GitHub Pages.

Les informations personnelles et les projets présentés sont basés sur le CV et le portfolio fournis.
